# Contributing to QR Link Opener

Thank you for contributing.

## Development setup

Use Windows and Python 3.12 or later. Create a virtual environment, install `requirements.txt`, and run the unit tests described in the README before opening a pull request.

## Pull requests

- Keep changes focused and include tests for changed QR decoding or URL-classification behavior.
- Do not add telemetry, cloud uploads, or automatic URL opening without an explicit opt-in design discussion.
- Keep user-visible Chinese and English text clear and consistent.

## Security reports

Do not open a public issue for a suspected security vulnerability. Contact the repository owner privately through GitHub instead, including a clear reproduction and impact description.
